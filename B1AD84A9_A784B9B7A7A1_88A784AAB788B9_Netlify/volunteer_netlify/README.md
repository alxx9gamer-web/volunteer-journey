# رحلة العطاء والتطوع — نسخة لوحة عامة بدون كلمة مرور

هذه النسخة تجعل `/admin.html` متاحًا لأي زائر بلا كلمة مرور، بما في ذلك وظيفة بدء جولة جديدة؛ لذلك هي غير مناسبة لموقع عام يشارك فيه طلاب حقيقيون دون رقابة.

## النشر
ارفع محتويات هذا المجلد مباشرة إلى جذر مستودع GitHub (لا ترفع مجلدًا إضافيًا)، ثم اضبط Base directory في Netlify إلى جذر المستودع وPublish directory على `public` وFunctions directory على `netlify/functions`.

لا تحتاج متغير `TEACHER_ADMIN_PASSWORD` في هذه النسخة. يجب إعادة النشر حتى تُطبّق التغييرات.

## الخصوصية
أسماء وصفوف الطلاب الذين لم يوافقوا على نشر أسمائهم تُخفى في شاشة المشرف العامة وفي ملف CSV، لكن نتائجهم الإحصائية تُعرض.

**تحذير:** يستطيع أي شخص يزور `/admin.html` إنشاء جولة جديدة وتغيير لوحة الشرف. للحماية الحقيقية يجب إضافة تسجيل دخول أو تفويض على الخادم.
