# رحلة العطاء والتطوع — نسخة نظيفة للنشر

## محتوى النسخة
- 10 أسئلة عن العمل التطوعي بترتيب عشوائي.
- مدة كل سؤال 90 ثانية، وتُعاد من البداية لكل سؤال.
- نتائج وشهادات ولوحة شرف عامة للأسماء التي وافقت على الظهور وحققت 7/10 فأكثر.
- `/admin.html` لوحة إدارة بدون كلمة مرور، تعرض إحصاءات الجولات وتحفظ الجولة السابقة عند بدء جولة جديدة، وتصدر CSV.

## رفع المشروع
1. **لا ترفع ملف ZIP نفسه إلى GitHub.** فك ضغطه.
2. ارفع `public` و`netlify` و`netlify.toml` و`package.json` و`README.md` مباشرة إلى **جذر** المستودع، بدون مجلد إضافي.
3. في Netlify: Base directory فارغ؛ Publish directory = `public`؛ Functions directory = `netlify/functions`؛ Build command فارغ.
4. استخدم GitHub-connected deploy؛ لا تستخدم Netlify Drop لأن وظائف حفظ النتائج تحتاج بناء Functions والتبعيات.
5. يجب أن يظهر في الموقع «دقيقة ونصف لكل سؤال»؛ وفي الأسئلة يبدأ المؤقت بـ 90 ثانية.

## تنبيه
لوحة المشرف بلا كلمة مرور: أي شخص يعرف عنوان `/admin.html` يستطيع فتحها، قراءة النتائج المسموح بنشرها، وإنشاء جولة جديدة. لا تستخدم هذا الإعداد لبيانات مدرسية حساسة. لا تضع بيانات تعريف شخصية لا ترغب بنشرها.

النتائج المخزنة في Netlify Blobs لا تُحذف بالضرورة بحذف الملفات من GitHub؛ تستمر وفق تخزين الموقع، ويجب حذفها بشكل منفصل إذا أردت ذلك.
