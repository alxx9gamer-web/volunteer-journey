# رحلة العطاء والتطوع – مسابقة مدرسية تفاعلية

## النشر الصحيح على Netlify
1. ارفع مجلد المشروع كاملًا إلى مستودع GitHub ثم اربطه بخدمة Netlify (Import an existing project).
2. إعداد النشر موجود في `netlify.toml`: مجلد النشر `public` ومجلد الوظائف `netlify/functions`.
3. يعتمد حفظ النتائج ولوحة الشرف على Netlify Functions وNetlify Blobs دون الحاجة لإعداد مفاتيح سرية.
4. لا تستخدم رفع `index.html` وحده أو سحب مجلد `public` فقط؛ هذا سيعرض اللعبة لكنه لن يفعّل حفظ النتائج المشترك.
5. جرّب الموقع بعد أول نشر من متصفحَين مستقلين وتأكد من ظهور الاسم المصرّح بنشره بعد إكمال 7 إجابات صحيحة على الأقل.

## السلوك
- 10 أسئلة من الملف الأصلي، ترتيب عشوائي لكل محاولة، 25 ثانية للسؤال.
- تُحسب النتيجة النهائية وتُتحقق الإجابات مجددًا في وظيفة Netlify.
- يعرض قسم الشرف أسماء الطلاب الذين وافقوا على النشر وحصلوا على 7/10 أو أكثر.
- محاولات الطلاب الآخرين لا تظهر بأسمائهم ما لم يوافقوا على العرض.
- التقدم والشهادة متاحان لكل مشارك حتى إذا تعذر الاتصال بخدمة الحفظ، مع تمييز عدم حفظ النتيجة.

## ملاحظات مهمة
- لا توجد حسابات تسجيل دخول: يستطيع أي شخص كتابة اسم يدويًا؛ لا توجد وسيلة للتحقق من الهوية في هذا الإصدار. التحقق من الإجابات يتم في الخادم، لكن يمكن لمن يجيد أدوات المتصفح إرسال بيانات مصطنعة. ليست منصة امتحانات مراقبة.
- `Netlify Blobs` مناسب للنشاط المدرسي محدود الحجم. عند آلاف المحاولات أو الحاجة إلى إدارة مدرسية وتصنيف فصلية آمن، يفضل قاعدة بيانات مع نظام دخول ومراجعة.
- لا تنشر أسماء الطلاب بدون موافقة مناسبة وفق سياسات المدرسة وأولياء الأمور. خيار الموافقة غير مفعّل افتراضيًا.

## لوحة المعلم (الإصدار 2)
- افتح `/admin.html` بعد النشر.
- في Netlify → Site configuration → Environment variables أضف `TEACHER_ADMIN_PASSWORD` بكلمة مرور قوية طولها 12 حرفًا على الأقل، نطاق **Functions** أو **All scopes**. ثم أعد النشر لتصل القيمة إلى الوظائف. **لا تكتبها في GitHub أو ملفات المشروع**.
- اختر «بدء جولة جديدة» لمسح لوحة الشرف الظاهرة للطلاب دون حذف نتائج الجولات السابقة. سجل النتائج السابقة متاح من اختيار الجولة في لوحة المعلم.
- صدّر نتائج الجولة المعروضة إلى CSV يفتح في Excel.
- لا ترفع مجلد المشروع ضمن مجلدات إضافية بدون ضبط Base directory في إعدادات Netlify.
- كلمة المرور ليست حسابًا متعدد المستخدمين، ولا يوجد حد محاولات دخول على مستوى التطبيق؛ استخدم كلمة مرور طويلة وفريدة، وللإنتاج المدرسي الرسمي يوصى بخدمة هوية وحد محاولات (rate limiting).
- المشارك الذي يرسل نتيجته بعد بدء الجولة التالية يُحسب ضمن الجولة النشطة عند لحظة إرسالها؛ لتفادي ذلك ابدأ الجولة قبل دخول الطلاب.
